# Workspace

Uma Área de Trabalho para meus arquivos de script e de configuração de aplicações que eu comumente uso no Linux e no Windows.

## Scripts
- commit: Script de automação de commit e push do git.
- initialize: Script de automação para inicialização de repositórios.
- extensions: Script de automação de instalação de extensões do VS Code.
- pos-install: Script de automação de pós instalação do Pop!_OS.

- Bash
- Gedit
